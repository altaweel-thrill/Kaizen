# لوحة طلبات Kaizen

الرابط المنشور: https://kaizen-44bef.web.app/admin/

## تسجيل الدخول

1. أدخل بريد المدير `altaweel@thrillagency.net` وكلمة مرور حسابه، ثم اضغط **تسجيل الدخول**.
2. عند نسيان كلمة المرور، اختر **نسيت كلمة المرور؟**.
3. إذا كان البريد غير مؤكد، افتح رابط التأكيد ثم اضغط **تحقّق من التفعيل**.

لا توجد إمكانية إنشاء حساب من اللوحة. الحسابات الجديدة تُجهّز من Firebase Authentication بواسطة إدارة المشروع.

كلمة المرور تديرها Firebase Authentication ولا تُحفظ في كود الموقع أو مستودع Git. الرسائل الخاصة بتأكيد الحساب واستعادة كلمة المرور منفصلة عن طلبات التقييم؛ طلبات التقييم لا ترسل بريدًا.

## وظائف اللوحة

- عرض الطلبات مرتبة من الأحدث، مع تفاصيل الاسم وواتساب والهدف والوقت والاستعداد الصحي.
- إجماليات لجميع الطلبات، وبحث وتصفية في الطلبات المحمّلة.
- خمسون طلبًا في كل دفعة وزر تحميل المزيد.
- تحديث الحالة: جديد، تم التواصل، تم تحديد موعد، مكتمل، مؤرشف.
- تسجيل تاريخ تحديث الحالة والبريد الذي حدّثها، ورابط للتواصل عبر واتساب.
- تحديث تلقائي كل دقيقة عندما تكون الصفحة ظاهرة والتفاصيل مغلقة.
- تصميم عربي RTL متجاوب، وتسجيل خروج يمسح عرض بيانات العملاء من الصفحة.

## الحماية

خدمة `adminAssessments` تتحقق من Firebase ID token ومن البريد المؤكد ومن قائمة `ADMIN_EMAILS` على الخادم. لا تمنح الواجهة وحدها صلاحية الوصول، وتبقى قواعد Firestore العامة مغلقة. لا يُسمح بحذف الطلبات من لوحة التحكم.

عند السماح لمدير إضافي، حدّث `ADMIN_EMAILS` في `functions/.env` وأعد نشر خدمة الإدارة؛ لا تنشئ صلاحيات قراءة عامة في Firestore.

```bash
firebase deploy --only functions:kaizen-leads:adminAssessments --project kaizen-44bef
```

لنشر ملفات اللوحة فقط على Firebase Hosting:

```bash
firebase deploy --only hosting --project kaizen-44bef
```

مهمة التحضير تنسخ خمسة ملفات عامة فقط إلى `.firebase/admin-public`. لا تنشر إعدادات الخادم أو كلمات المرور. الموقع العام على GitHub Pages منفصل عن لوحة Firebase.

محليًا: `npm run dev` ثم افتح http://localhost:8765/admin/ . أعد تشغيل الخادم إذا كان يعمل قبل إضافة مسار اللوحة.

## الاختبارات

`npm test` يفحص التحقق من الجلسات والصلاحيات والحالات وحفظ الطلبات. الاختبار البصري `tests/admin-ui-check.cjs` يستخدم جلسة ومتطلبات وهمية معزولة، ولا يتجاوز مصادقة الخدمة المنشورة. تم فحص رفض الخدمة الحية للطلبات بلا جلسة وبجلسات مزورة؛ الدخول الفعلي يتطلب حساب المدير المؤكد.
